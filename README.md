# Give Me the Bible Crosswords: iPhone/iPad build

Upload everything in this folder (including the hidden `.github` folder) to a new GitHub repository.
GitHub then builds an unsigned `GiveMeTheBibleCrosswords-unsigned.ipa` automatically (Actions tab → latest run → Artifacts).
Install it on your iPhone or iPad with Sideloadly (Windows or Mac) or AltStore, signing with your free Apple ID.
Free Apple ID installs must be refreshed every 7 days.

Build method adapted from github.com/adro0303/ipa-builder (MIT).
